# 0. Wymagania wstępne

**Przed warsztatem każdy uczestnik:**

1. **Konto na ElevenLabs** — https://elevenlabs.io → Sign up (plan free wystarczy)
2. **Nagranie własnego głosu (~1 minuta)** — telefon/komputer, ciche miejsce; plik WAV lub MP3.
   Przyda się do:
   - transkrypcji własnego nagrania (STT),
   - text-to-speech / klonowania głosu (TTS),
   - porównania API vs lokalny Whisper.
3. **Konto Google** — do Google Colab (część warsztatowa).
4. Opcjonalnie: przeglądarka z dostępem do https://colab.research.google.com
