# 1. Wprowadzenie do ASR — 10 min (Franek)

**Cel:** wspólne słownictwo i mapa trzech zagadnień warsztatu.

## Program
1. Czym jest **speech-to-text (transkrypcja)** — mowa → tekst
2. Czym jest **text-to-speech** — tekst → mowa (syntetyczny głos, voice cloning)
3. Czym jest **diaryzacja** — kto mówi i kiedy (rozdzielenie mówców)
4. Jak to się łączy: transkrypcja spotkania + diaryzacja + streszczenie (podgląd do bloku API)
